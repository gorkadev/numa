# Tiny Swords template (first 2D template)

Objective: support 2D pixel-art games on the existing three.js engine (no second engine) and ship `tiny-swords@1` from the Pixel Frog "Tiny Swords (Free Pack)".
Branch: `feat/tiny-swords-template`. Delivery: ask-on-risk, forecast ~1000 authored lines (excluding generated ASSETS.json and asset bytes); chain strategy assumed `stacked-to-main` as in prompt-improver (user: "me da igual"), slices decided at PR time. Runner: `pnpm --filter web exec tsx --test <file>`.

## Specs

- S1 Engine 2D modules (option B, "un solo motor"): `runtime/engine/sprites.js` loads pixel-art textures crisp (nearest filter, sRGB, no tone mapping) and plays single-row sprite sheets with explicit `frameWidth`/`frameHeight`/`frames`/`fps`, flip and anchor; `runtime/engine/tilemap.js` draws a 64px tile grid from a tileset atlas by tile name or index, in layers, with y-sorting helpers for top-down depth. Exported from `index.js`; covered by tests that run the plain JS like `engine-guards.test.ts`.
- S2 Skill `engine-2d` in the registry explaining 2D on the engine (orthographic camera, pixels per world unit, sprites, tilemap, depth ordering). Not a role default (3D games pay nothing); loadable with `load_skill` and selectable per task.
- S3 Template contract accepts 2D assets, additive and optional: manifest `sprites` (id, path, category, frameWidth, frameHeight, frames, fps) and `tilesets` (id, path, tileSize, columns, rows, named tiles); declared/undeclared path checks cover them; `models` may be empty; the planner context lists the 2D inventory and points at `engine-2d`; a template with no glTF models requires no eager-model receipt (the receipt and readiness check are glTF-only). Existing templates unchanged.
- S4 `tiny-swords@1`: every PNG of the free pack except `.aseprite` sources and the store-page banners; frame sizes verified by a transparent-boundary test (Tree1/Tree2 are 192x256, not square); tilesets with the verified tile names (flat 0-2/9-11/18-20, strips 3/12/21 and 27-29, single 30; elevated 5-7/14-16/23-25, 8/17/26, 32-34, 35; cliffs 41-44 grass base, 50-53 water base; stairs 36+45, 39+48); TEMPLATE.md with layer order (water colour, foam, flat ground, shadow + elevated per level), shadow/foam are 192x192 centred on the tile, 10 fps, default example (assumption: small top-down action/gather game, example only). Registered in catalog, seed registry and both locales; bytes in R2 behind `ASSETS.lock.json`. License: user confirmed usage with Pixel Frog (2026-10-28) ("ya tengo la confirmacion de la licencia").
- S5 Smoke test: a real game generated with the template.
